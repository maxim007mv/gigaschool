# S03 · Уточняющие вопросы

## Цель
Сформулировать не более пяти уточняющих вопросов по незаполненным слотам,
чтобы агент не додумывал обязательные параметры (ТК4-1: 409 CLARIFICATION_REQUIRED
пока обязательные слоты пусты).

## Вход
- `missing_slots` (или из S01) — слоты без значения;
- `S01` — профиль программы; `S02` — выбранный вид (снимает слот `kind`);
- настройка `MAX_QUESTIONS` (по умолчанию 5).

## Правила (таблица 4.3)
1. Обязательные слоты: kind, total_hours, audience, entry_level, form, final_attestation.
2. Вопросов не больше `MAX_QUESTIONS`; каждый — с вариантами-кнопками и пояснением «зачем».
3. «Примерно месяц» не считается объёмом — объём спрашивается числом часов.
4. Если слотов больше лимита, менее важные (срок, режим) берутся по умолчанию
   и записываются в `assumptions`.
5. Формулировки без технического жаргона; непокрытые обязательные слоты
   добираются детерминированными шаблонами из кода навыка.

## Выход (schema.json)
`{questions[{slot, question, why, options[], required}], assumptions[]}`

## Зависимости
- S01 (разбор брифа), S02 (вид программы).

## Проверка после шага
- вопросов ≤ MAX_QUESTIONS; все `slot` — из переданного списка незаполненных;
- каждый обязательный слот либо покрыт вопросом, либо попал в `assumptions`;
- вопросов по слоту `kind` нет, если вид уже выбран в S02.

## Модель
Класс `bulk` (массовая модель, temperature 0,5): формулировки вопросов — не критичная структура.
