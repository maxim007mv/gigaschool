# S17 · Литература и ресурсы

## Цель
Собрать кандидатов источников по разделам: НПА, основная и дополнительная
литература, интернет-ресурсы, ПО и сервисы. Кандидаты проверяются в S18 —
до проверки все источники помечены как неподтверждённые.

## Вход
- темы и модули программы (из S11/S10-контекста);
- реестры НПА/профстандартов (если доступны) — для `normative_act_ref`;
- фрагменты RAG базы знаний организации.

## Правила
1. НПА попадают в документ только из реестра: без кода реестра — `normative_act_ref=null`
   и пометка «не подтверждено» после S18 (V-SRC-01).
2. Литература: не старше ~5 лет для основной, классика допускается в дополнительной.
3. Интернет-ресурсы — официальные домены; ПО и сервисы — доступные в РФ.
4. Дубли (по нормализованной цитате) удаляются; refs: SRC-01, SRC-02, …
5. Источник без цитаты отбрасывается.

## Выход (schema.json)
`{sources[{ref, section, citation, url, isbn, normative_act_ref}], notes}`

## Зависимости
- S11 (рабочие программы модулей) — тематический контекст.

## Проверка после шага
- section ∈ normative|main|additional|internet|software; refs уникальны и последовательны;
- ISBN нормализован (цифры и дефисы), URL — строка;
- список отсортирован по разделам, объём разумный (≤ 60 источников).

## Модель
Класс `bulk` (temperature 0,5): черновик списка; строгую проверку делает S18.
