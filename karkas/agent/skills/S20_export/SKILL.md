# S20 · Экспорт комплекта

## Цель
Сформировать артефакты выгрузки из KitV1: программу .docx, слайды .pptx, тесты
GIFT / Moodle XML / CSV, комплект .json и отчёт .docx. Файлы НЕ пишутся:
навык возвращает байты/строки, сохранение — задача инфраструктуры (S3).

## Вход
- `kit` (или `ctx.extra["kit"]`) — утверждённый комплект;
- `formats` — подмножество {docx, pptx, gift, moodle_xml, csv, json, report};
- `module_refs` — для .pptx: модули, по которым делаются слайды;
- `report` или `S19.report` — отчёт самопроверки для .docx-отчёта.

## Правила
1. Сериализаторы — только из `karkas.infra.exporters` (ARTIFACT_KINDS или
   замороженные имена `export_*`); логика форматов в навыке не дублируется.
2. Неизвестный формат → ошибка шага (Д4 §10: formats — подмножество).
3. Поля приказа, ФИО и подписи остаются пустыми подчёркиваниями (V-TPL-03).
4. Файлы не пишутся на диск; результат — `{kind: bytes|str}`.

## Выход (schema.json)
`{docx: bytes, pptx: bytes, gift: str, moodle_xml: str, csv: str, json: str, report: bytes}`

## Зависимости
- S19 (самопроверка комплекта).

## Проверка после шага
- для каждого запрошенного формата вызван экспортёр; пустой результат — ошибка;
- .json соответствует JSON Schema kit.v1; тесты LMS содержат ключи и теги РО;
- плейсхолдеры приказа/подписей пусты.

## Модель
Чистый код (`model_class=none`), LLM не вызывается.
