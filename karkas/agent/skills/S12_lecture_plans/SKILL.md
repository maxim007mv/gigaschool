# S12 · Планы лекций

## Цель
Составить план лекции по каждой теме: цели, этапы с минутами, вопросы для
самопроверки, материалы. План становится источником слайдов (S13) и заметок
докладчика в .pptx.

## Вход
- `topic` — тема каркаса `{ref, title, summary, outcome_refs}`;
- `module_ref` — модуль темы;
- `S11` — рабочая программа модуля (аннотация и содержание темы);
- `outcomes` — результаты обучения темы.

## Правила
1. Этапы суммарно соответствуют часам темы (лекционная часть); минуты целые > 0.
2. Каждый этап — наблюдаемое действие (лекция, разбор, демонстрация, опрос).
3. Вопросы для самопроверки — по РО темы, без выхода за формат.
4. Для стажировки вместо лекции — задания СРС и вопросы собеседования (Д4 §5.6).

## Выход (schema.json)
`{lecture_plans[{ref, kind:"lecture_plan", module_ref, topic_ref, title, body{goals[], stages[{minutes,
stage, activity, notes}], questions[], materials[], notes}}]}`

## Зависимости
- S11 (рабочая программа модуля).

## Проверка после шага
- ref вида `LP-T1.1`; этапы непустые, минуты ≥ 0, дубли этапов удалены;
- тема плана совпадает с темой каркаса; выход не содержит других тем;
- Σ минут этапов ≤ часов темы × 60.

## Модель
Класс `bulk` (temperature 0,5). Вызывается параллельно по темам (граница — семафор шлюза).
