# S13 · Слайды лекции

## Цель
Собрать структуру слайдов по плану лекции: титул темы, 5–12 содержательных
слайдов, практика, вопросы для самопроверки. Структура затем рендерится в .pptx
экспортёром (S20).

## Вход
- план лекции из S12 (`lecture_plans[0]`);
- тема каркаса `{ref, title}` и модуль;
- пожелания брифа (для каких занятий делать слайды).

## Правила
1. Слайды строятся ТОЛЬКО по плану лекции — темы совпадают по построению (V-REQ-01).
2. Содержательных слайдов 5–12; больше — обрезается с пометкой `trimmed`.
3. На слайде не больше 8 пунктов; пункты — короткие тезисы, не абзацы.
4. Заметки докладчика — из плана лекции (этапы, пояснения).
5. Для школьников — простой язык и примеры; термины поясняются.

## Выход (schema.json)
`{slides[{ref, kind:"slides", module_ref, topic_ref, body{title, slides[{title, bullets[], notes}], source_ref}], notes, trimmed}`

## Зависимости
- S12 (план лекции).

## Проверка после шага
- у каждого слайда непустой заголовок; число пунктов ≤ 8;
- общее число слайдов ≤ 12 (`trimmed` показывает, сколько обрезано);
- ref вида `SL-T1.1`; пустой список слайдов — ошибка шага.

## Модель
Класс `bulk` (temperature 0,5); по умолчанию слайды делаются для модуля/занятий из брифа,
минимум для одного модуля (требование кейса).
