# S11 · Рабочие программы модулей

## Цель
Собрать рабочую программу модуля: аннотацию, содержание тем и формы работы —
строго по темам утверждённого каркаса (граница Human Gate уже пройдена).

## Вход
- `module` — модуль каркаса `{ref, title, topics[{ref, title, summary}]}`;
- `outcomes` — результаты обучения темы (для содержания);
- `profile` — аудитория, входной уровень, глоссарий;
- фрагменты RAG базы знаний организации (если загружены).

## Правила
1. «Контекстный паспорт темы»: РО темы, соседние темы (без повторов), глоссарий,
   профиль аудитории, доступные в РФ сервисы, обезличенные данные примеров.
2. В программу попадают только темы модуля; чужие `topic_ref` отбрасываются.
3. Тексты — авторские: дословное копирование референсов запрещено (V-PLG-01).
4. Для школьников — упрощённый регистр, термин поясняется при первом упоминании.

## Выход (schema.json)
`{module_programs[{ref, kind:"module_program", module_ref, topic_ref, body{annotation, topics[{topic_ref,
summary, work_forms[], materials[]}], att_form}}], notes}`

## Зависимости
- S10 (проверенный каркас).

## Проверка после шага
- ref вида `MP-M1`; `module_ref` совпадает с модулем каркаса;
- темы body ⊆ темам модуля; пустой список тем — ошибка шага;
- формы работы соответствуют видам занятий из сетки часов (ЛК/ПР/ЛБ/СРС).

## Модель
Класс `bulk` (массовая генерация, temperature 0,5). Вызывается параллельно по модулям.
