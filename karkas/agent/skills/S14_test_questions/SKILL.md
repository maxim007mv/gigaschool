# S14 · Тестовые вопросы с ключами

## Цель
Сгенерировать тестовые вопросы с вариантами, ключом, пояснением и привязкой к
результатам обучения. Каждый вопрос обязан иметь ключ и `outcome_refs` (V-COV-04).

## Вход
- `outcomes` — РО программы (для привязки);
- `topics` (или `module.topics`) — темы, к которым относятся вопросы;
- `count` — желаемое число вопросов (мягкое пожелание);
- профиль аудитории (уровень сложности, регистр формулировок).

## Правила
1. У каждого вопроса — не менее двух вариантов (для single/multiple) и верный ключ.
2. `outcome_refs` — только существующие РО; связь не выдумывается.
3. Тип вопроса ∈ single | multiple | truefalse | short | matching | order | open.
4. Сложность 1–5; формулировка проверяет действие, а не память на формулировку.
5. По каждому РО — минимум 2 оценочных средства за всю программу
   (MIN_ASSESSMENTS_PER_OUTCOME); вклад S14 виден в покрытии S19.

## Выход (schema.json)
`{questions[{ref, kind:"test_question", topic_ref, module_ref, stem, qtype, options[{id,text}],
answer_key{correct[], explanation}, outcome_refs[], difficulty}], dropped[], count}`

## Зависимости
- S11 (рабочая программа модуля).

## Проверка после шага
- вопросы без ключа, без РО или с «висячим» правильным вариантом отбрасываются в `dropped`;
- если не осталось ни одного валидного вопроса — ошибка шага (повтор генерации);
- refs вопросов нормализуются: `Q-001`, `Q-002`, …

## Модель
Класс `bulk` (temperature 0,5). Запускается параллельно с S15/S13 после S11.
