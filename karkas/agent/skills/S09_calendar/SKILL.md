# S09 · Календарный учебный график

## Цель
Разложить часы тем по неделям и дням с ограничением «не более N часов в день»
и числом учебных дней в неделю; итоговая аттестация не дробится (Д4 §5.5).

## Вход
- `S08` (или `rows`/`distance`/`module_of`) — сетка часов из солвера;
- `constraints` — объём, часы ИА, кратность занятия;
- `max_hours_per_day` (по умолчанию из ограничений), `days_per_week`.

## Правила
1. Раскладку делает `karkas.domain.calendar.calendar` — логика не дублируется.
2. Календарные даты для ДПП не проставляются: в графике только недели и дни
   («формируется по мере комплектования групп»).
3. Итоговая аттестация — отдельная запись с `topic_ref=null`, не дробится.
4. Вид деятельности занятия — доминирующий вид работ темы из сетки часов;
   режим — `distance`, если у темы есть часы ДОТ.

## Выход (schema.json)
`{weeks, days, days_per_week, max_hours_per_day, sessions[{seq, week, day, topic_ref, activity, mode, hours}]}`

## Зависимости
- S08 (солвер часов).

## Проверка после шага
- V-CAL-01: число дней и недель покрывает все часы, ≤ N часов в день;
- Σ часов занятий = Σ часов тем + часы ИА;
- `seq` неубывающий, ИА — одним занятием.

## Модель
Чистый код (`model_class=none`), LLM не вызывается.
