# S15 · Задания семинаров

## Цель
Составить практические задания для семинаров и практикумов с критериями оценки
(rubric) и привязкой к результатам обучения. Задание без критериев не принимается
(`kind=seminar_task` требует rubric в модели KitV1).

## Вход
- `topics` — темы программы с РО;
- `outcomes` — результаты обучения;
- профиль аудитории (уровень, доступные инструменты, обезличенные данные).

## Правила
1. Каждое задание — проверяемое действие с наблюдаемым результатом.
2. Критерии: 2–5 пунктов, у каждого баллы > 0 и уровни («выполнено»/«не выполнено»).
3. `outcome_refs` — только существующие РО.
4. Инструменты и данные — доступные в РФ; персональные данные не используются.
5. Формулировки авторские, без дословных копий референсов (V-PLG-01).

## Выход (schema.json)
`{tasks[{ref, kind:"seminar_task", topic_ref, module_ref, stem, rubric[{criterion, max_points, levels[]}],
outcome_refs[]}], dropped[], count}`

## Зависимости
- S11 (рабочая программа модуля).

## Проверка после шага
- задания без rubric или без РО отбрасываются в `dropped` с причиной;
- у критериев положительные баллы, уровни непустые;
- refs заданий: `ST-T1.1-1`, `ST-T1.1-2`, …

## Модель
Класс `bulk` (temperature 0,5). Запускается параллельно с S13/S14 после S11.
