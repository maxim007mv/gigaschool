# Эталонные комплекты УМК (примеры результатов КАРКАС)

В данном каталоге собраны эталонные комплекты учебно-методических материалов (УМК),
сгенерированные сервисом КАРКАС и прошедшие полную детерминированную самопроверку
по официальным чек-листам хакатона «Точка сборки» (Кейс №1: «Агенты и EdTech»).

---

## 1. Состав каждого примера

Для каждого кейса сформирован полный пакет артефактов без необходимости вызова внешних LLM:

| Файл | Назначение | Стандарт / Спецификация |
|------|------------|-------------------------|
| `program_*.docx` | Учебная программа | 10 обязательных разделов по официальному эталону АЦР (Д4 §5.12, V-ACR-01) |
| `presentation_*.pptx` | Презентация курса | Титульный слайд, модули, темы, практические задания, заметки спикера |
| `kit_*.json` | Полная модель данных | Спецификация `KitV1` (Pydantic v2): ЗУН, матрица покрытия, сетка часов, календарь |
| `tests_*.gift.txt` | Банк тестовых заданий | Формат GIFT для импорта в LMS Moodle (вопросы с вариантами, дистракторы, фидбек) |
| `report_*.docx` | Отчёт самопроверки | Результаты прогона 20+ валидаторов (V-HRS, V-COV, V-CAL, V-SRC, V-ACR) |

## 2. Кейс ТК-1: «Первые шаги в Python» для школьников 8–9 классов

- **Каталог:** [`examples/tk1/`](tk1/)
- **Исходный запрос (бриф):**  
  > *«Нужна дополнительная общеразвивающая программа «Первые шаги в Python» для школьников 8 и 9 классов без опыта программирования. Объем 16 часов, занятия очно по 2 часа два раза в неделю. Практики должно быть не меньше половины всех часов.»*
- **Тип программы:** Дополнительная общеразвивающая программа (ДОП, приказ Минпросвещения № 629).
- **Объём:** 16 академических часов (8 занятий по 2 часа, 4 недели, очно).
- **Практика:** 10 часов (62.5% при минимальном требовании ≥ 50%).
- **Профстандарты:** Не привязаны (согласно 273-ФЗ для ДОП профстандарты не применяются).
- **Результат чек-листа:** **6/6 (100% пройден)**:
  - `[OK] TK-ОБЩ-1`: Сумма часов модулей + ИА = 16 ч (заявлено 16 ч).
  - `[OK] TK-ОБЩ-2`: Темы с нулевыми часами отсутствуют.
  - `[OK] TK-ОБЩ-3`: Структура `.docx` полностью соответствует эталону АЦР.
  - `[OK] TK1-1`: Шаблон `dop`, практические занятия 10 ч.
  - `[OK] TK1-3`: График 8 занятий по 2 часа, укладывается ровно в 4 недели.
  - `[OK] TK1-9`: Профстандарты и трудовые функции отсутствуют.
- **Измеренные метрики живого прогона (GigaChat-3-Pro на Cloud.ru FM):**
  - Время генерации полного комплекта (Wall time): **173 с** (~2.9 мин, норматив ≤ 20 мин).
  - Число вызовов LLM: **38**.
  - Токены: **73 500** токенов.
  - Оценочная стоимость: **7.25 ₽** (лимит хакатона 100 ₽/день).

## 3. Кейс ТК-2: «Искусственный интеллект в работе учителя»

- **Каталог:** [`examples/tk2/`](tk2/)
- **Исходный запрос (бриф):**  
  > *«Программа повышения квалификации для школьных учителей «Искусственный интеллект в работе учителя». Объем 36 часов, очно-заочная форма с применением дистанционных технологий. Должен использоваться профессиональный стандарт педагога.»*
- **Тип программы:** Дополнительная профессиональная программа повышения квалификации (ДПП ПК, приказ Минобрнауки № 499 / 273-ФЗ).

- **Результат чек-листа:** **7/7 (100% пройден)**:

  - `[OK] TK-ОБЩ-2`: Тем без часов нет.

  - `[OK] TK2-1`: Шаблон `dpp_pk`, объём 36 ч.
  - `[OK] TK2-2`: Контактные часы 34 ч, дистанционные 16 ч (≥ 8 ч).
  - `[OK] TK2-3`: Компетенции привязаны к утверждённому ПС 01.001.
  - `[OK] TK2-4`: Вопросы этики генеративного ИИ и защиты ПДн раскрыты в темах.
- **Измеренные метрики живого прогона:**

## 4. Как воспроизвести проверку качества без LLM-ключа

Для проверки эталонных артефактов запуск языковой модели не требуется — все валидаторы работают детерминированно:

```bash
# Проверка кейса ТК-1
.venv/bin/python scripts/run_eval.py --kit examples/tk1/kit_tk1.json --case tk1

# Проверка кейса ТК-2
.venv/bin/python scripts/run_eval.py --kit examples/tk2/kit_tk2.json --case tk2
```
