# Эталонные комплекты УМК (примеры результатов КАРКАС)

В каталоге лежат два комплекта, сгенерированных вживую сервисом КАРКАС:
GigaChat-3-Pro через шлюз Cloud.ru Foundation Models, коммит `e63e012`
(19.10.2026). Метрики взяты из `metrics.json` соответствующего каталога;
файлы `.docx`, `.pptx` и тесты собраны экспортёрами из `kit_*.json`,
а не написаны вручную.

Статусы верификации источников в `kit_*.json` приведены к фактическому состоянию
(неподтверждённые НПА/ПО не помечены как `verified`). Комплекты будут
перегенерированы при следующих живых прогонах; метрики в `metrics.json` не менялись.

## 1. Состав комплекта

| Файл | Назначение |
|------|------------|
| `program_*.docx` | Программа по структуре АЦР (полноту разделов проверяет V-ACR-01) |
| `presentation_*.pptx` | Слайды с заметками докладчика (выход S13) |
| `kit_*.json` | Полная модель `KitV1`: ЗУН, темы, часы, оценки, отчёт |
| `tests_*.gift.txt` | Банк тестов в формате Moodle GIFT |
| `tests_*.moodle.xml` | Тот же банк в формате Moodle XML |
| `report_*.docx` | Отчёт самопроверки V-* (ошибки, предупреждения, пробелы) |
| `metrics.json` | Измеренные время, вызовы, токены, стоимость и результат проверок |

## 4. Как проверить качество без LLM-ключа

```bash
# Чек-лист + полная самопроверка V-* по ТК-1
.venv/bin/python scripts/run_eval.py \
  --kit examples/tk1/kit_tk1.json --case tk1 --validate

# То же по ТК-2
.venv/bin/python scripts/run_eval.py \
  --kit examples/tk2/kit_tk2.json --case tk2 --validate
```

`--validate` прогоняет `run_validation` (V-HRS, V-COV, V-CAL, V-SRC, V-ACR,
V-CNT, V-LNG и остальные) и печатает ошибки. Код возврата ненулевой, если
чек-лист или полная проверка не прошли.

Пересобрать файлы примера из live-комплекта:

```bash
.venv/bin/python scripts/export_kit_artifacts.py \
  --kit data/eval/reports/tk1_live_kit.json \
  --metrics data/eval/reports/tk1_live_report.json \
  --out examples/tk1 --prefix tk1
```
