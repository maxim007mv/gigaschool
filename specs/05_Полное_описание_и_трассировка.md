# 1. Резюме решения

**КАРКАС** — веб-сервис и API, в котором ИИ-агент по свободному запросу методиста АЦР проектирует образовательную программу по ИТ-направлению любого объёма (16–500 ч и больше) и собирает комплект по шаблону АЦР: карту компетенций, учебный и учебно-тематический план, календарный график, рабочие программы модулей, тесты с ключами, задания семинаров с критериями, планы лекций со слайдами, список литературы. Выгрузка: .docx, .pptx, GIFT / Moodle XML / CSV и полный JSON.

| **Что важно жюри** | **Как отвечает КАРКАС** |
|:---|----|
| Каркас обучения (О. Сычугов: «буду очень глубоко проверять именно эту часть») | Каркас — отдельная фаза ≤ 3 мин. Часы распределяет детерминированный солвер, а не LLM; итоги не хранятся, а вычисляются из строк тем; утверждение каркаса с ошибкой блокируется в API и триггером БД |
| Согласованность и достоверность важнее красоты слайдов | Граф связей «компетенция → ЗУН → тема → вопрос/задание», 28 детерминированных проверок, реестры НПА и профстандартов: код, которого нет в реестре, не попадает в документ без пометки «не подтверждено» |
| Человек принимает решение | Human Gate: генерация содержания стартует только после утверждения каркаса; реквизиты приказа, ФИО и подписи остаются пустыми полями |
| Понятно методисту, без «разработческого куража» | Пять экранов на языке методиста; таблица часов с подсветкой расхождений; карточка «Агент заметил» вместо логов модели |
| Работоспособность на автопрогонах | Единый POST /api/v1/agent/run, минимум компонентов (FastAPI + PostgreSQL), только модели Cloud.ru, повторы и резервная модель |

# 3. Проблема, пользователи и ценность

## 3.1. Проблема (по тексту задачи и отчёту)

- Одна программа собирается вручную **от двух до восьми недель**, и даже после этого в ней остаются ошибки, которые всплывают при согласовании.

- Больше всего ошибок в **арифметике часов**, и их число растёт с объёмом программы (пример из действующей программы: модуль 246 ч СРС, а в итоговой строке 66 ч практик и 6 ч лабораторных при «контактной работе 0 ч»).

- Материал повторяется, нарушается логика, когда части готовят разные люди в разных файлах.

- ИТ-направления быстро устаревают — программы нужно регулярно обновлять.

- По отчёту, методисты тратят до 70 % времени на выверку формальных шаблонов.

Кейс просит на защите показать, сколько часов методиста экономит агент и сколько стоит комплект в токенах Cloud.ru. КАРКАС считает это по фактическим данным, без оценок «на глаз»:

## 13.1. Проектные допущения

- Нагрузка на отборочном этапе — единицы одновременных запросов; профиль развёртывания A (одна ВМ) достаточен, профиль B — для пилота (Д1 §10–11).
