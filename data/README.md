# Данные кейса (хакатон)

Сюда кладут материалы из личного кабинета «Точка сборки» (шаблоны программ АЦР,
открытые запросы, эталонные чек-листы). **Секреты и ключи API сюда не коммитить.**

## Структура

| Путь | Назначение |
|------|------------|
| `templates/` | Шаблоны программ АЦР (.docx) |
| `references/` | Примеры утверждённых программ |
| `open_requests/` | Тексты открытых запросов ТК-1…ТК-5 |
| `eval/` | Экспортированные комплекты `KitV1` в JSON (`tk1.json` … `tk5.json`) для автопроверки |

## Автоматическая оценка

```bash
.venv/bin/python scripts/run_eval.py
.venv/bin/pytest tests/eval -q
```

Если `data/eval/` пуст, тесты eval пропускаются; юнит-тест на эталонном KitV1 из тестовой фикстуры всё равно выполняется.
