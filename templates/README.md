# Шаблоны образовательных программ АЦР

В проекте КАРКАС есть два взаимодополняющих подхода к формированию документов.

1. **Встроенная генерация по структуре АЦР (по умолчанию):**
   экспортёры [`docx_program.py`](../karkas/infra/exporters/docx_program.py) и
   [`pptx_slides.py`](../karkas/infra/exporters/pptx_slides.py) собирают файлы
   программно, без внешних шаблонов, по структуре Академии цифрового развития
   (АЦР; полный перечень разделов — в
   [`acr_reference.py`](../karkas/domain/acr_reference.py), проверка V-ACR-01).
   Структура ДОП, ДПП ПК и стажировки различается.

2. **Эталонные документы и шаблоны:**
   официальные образцы программ АЦР лежат в [`data/templates/`](../data/templates/):
   - `acr_dpp_pk_staj_bsa_248h.docx` — эталон ДПП ПК / стажировки (248 ч);
   - `acr_dop_intensive_ai_24h.docx` — эталон ДОП (24 ч);
   - `product_brief_karkas.md` — продуктовый бриф Академии.

3. **Кастомизация через docxtpl:**
   для пользовательского бланка с Jinja-разметкой передайте файл в
   `export_docx_program(..., template_path=...)` — движок поддерживает
   шаблонизацию поверх docxtpl.
