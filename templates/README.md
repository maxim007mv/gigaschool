# Шаблоны выгрузок

Сюда кладутся мастер-шаблоны АЦР:

- `dpp_pk_template.docx` — пустой шаблон ДПП ПК (docxtpl, Jinja-метки);
- `dop_template.docx` — пустой шаблон ДОП;
- `slides_master.pptx` — брендированный мастер слайдов.

**Статус:** в материалах кейса шаблоны не переданы (пробел П-2, Д5 §13).
До получения шаблонов экспортёры `karkas/infra/exporters/docx_program.py` и
`pptx_slides.py` формируют документы программно (python-docx / python-pptx) по
структуре разделов из Д4 §5.12; при появлении файлов шаблонов достаточно
передать путь в `export_docx_program(..., template_path=...)` — код docxtpl уже
поддерживает этот режим.
