# СТРАТЕГИЧЕСКИЙ ПЛАН И ВЫВОДЫ ПО ПРОДУКТУ «КАРКАС»
**На основе транскрибации воркшопа Cloud.ru, церемонии открытия хакатона «Точка сборки» и анализа кодовой базы gigaschool**

---

## 1. Ключевые выводы из воркшопа Cloud.ru и выступлений экспертов

### Инсайт 1. Архитектура моделей (Александр Есин, Cloud.ru)
* **«Побеждает не самая большая модель, а правильная связка под задачу»:**
  * Попытка решить всё одной LLM приводит к перерасходу токенов, таймаутам и падению надежности.
  * *Рекомендованная трехуровневая связка:*
    1. **Легковесная быстрая модель (Qwen 7B / small):** классификация брифа, извлечение параметров, быстрый синтаксический чекинг.
    2. **Основная модель (GigaChat 3 Pro / Qwen):** логика агента, формулирование целей, декомпозиция компетенций и ЗУН по таксономии Блума.
    3. **Модель с длинным контекстом (DeepSeek V3 / R1):** глубокий анализ объемных нормативных актов, генерация развернутых конспектов лекций.
    4. **Модель эмбеддингов Cloud.ru:** векторный поиск по базе знаний (RAG).
* **Токеномика (Unit-экономика):**
  * Жюри оценивает экономическую целесообразность. Необходимо наглядно выводить расход токенов и себестоимость в рублях на курс (`GET /usage`).

### Инсайт 2. Ожидания заказчиков (Олег Сычугов, GigaCowork)
* **«Буду очень глубоко проверять именно каркас обучения»:**
  * Главная ценность — не тексты лекций, а строгость и верифицируемость каркаса.
  * Часы должны сходиться со 100% точностью (в КАРКАС это закрыто детерминированным солвером).
  * Обязателен **Human Gate**: запрет генерации контента до утверждения каркаса человеком.
  * Никакого «разработческого куража»: интерфейс должен быть интуитивным для методиста, без ML-жаргона.

### Инсайт 3. Методология и универсальность (Екатерина, методолог)
* **Адаптация под разные сегменты:**
  * Для ДПО — опора на 273-ФЗ и приказ № 499 (АЦР).
  * Для общеразвивающих программ и школ — приказ Минпросвещения № 629 и ФГОС.
  * Для ВУЗов — внутренние стандарты.
  * *Решение:* модуль **Knowledge Base (RAG)**, позволяющий методисту загружать свои локальные регламенты.

## 3. Пошаговый план действий команды (Action Roadmap)

### Этап 1. До Чекпоинта 1 (15 октября, до 16:59 МСК)
1. **Загрузка решения капитаном:**
   * Загрузить `Продуктовый_бриф_КАРКАС.pdf` на Яндекс.Диск / Google Диск.
   * Открыть доступ по ссылке для всех («Просмотр»).
   * Вставить ссылку в личном кабинете хакатона (вкладка «Сводка» → блок «Решение»).
2. **Репетиция питча в Zoom (3.5 минуты):**
   * Использовать готовый скрипт из файла `1.md`.
   * Продемонстрировать 5 экранов интерактивного прототипа (порт 8000).

### Этап 2. Подготовка к ежедневным автопрогонам (16–23 октября)
1. **Подключение к боевому API Cloud.ru Evolution:**
   * Заполнить `.env` выданным ключом `FM_API_KEY`.
   * Прописать боевые имена моделей: `MODEL_STRUCT`, `MODEL_BULK`, `MODEL_EMBED`.
2. **Валидация эндпоинта `POST /api/v1/agent/run`:**
   * Прогнать агент через `karkas.api.routers.agent` на 5 открытых тест-кейсах (ТК1–ТК5).
   * Особое внимание: тест-кейс 4 (неполный запрос — агент должен вернуть уточняющие вопросы и корректно продолжить работу после ответа).
3. **Деплой на сервере (порт 8000):**
   * Поднять стек на ВМ через `deploy/docker-compose.yml`.
   * Обеспечить доступность эндпоинта для автоматических тестов платформы с 06:00 до 10:00 МСК.

### Этап 3. Доработка до СТОП-КОДА (23 октября, Чекпоинт 2)
1. **Подключение Knowledge Base (RAG) в UI:**
   * Довести страницу `KbPage.tsx` до полноценного поиска по загруженным регламентам через pgvector.
2. **Дашборд токеномики (Unit-экономика):**
   * Выводить в веб-интерфейсе карточку: «Потрачено токенов: X · Стоимость генерации: Y руб.».
3. **Активация сверхплановых фичей:**
   * *S22 (Актуализация курса):* загрузка устаревшей программы → поиск устаревших библиотек/тем → предложение актуального аналога.
   * *S23 (Адаптация курса):* автоматическое сжатие программы 72 ч в 16 ч или смена целевой аудитории (школа / ВУЗ / ДПО).
4. **Запись демо-видео (2–3 минуты):**
   * Четкая демонстрация: ввод брифа → уточнения → проверка сетки часов (Human Gate) → генерация комплекта УМК → скачивание .docx и .pptx.
