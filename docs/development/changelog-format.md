# Формат changelog.md

После важных изменений продукта добавлять блок **сверху** (после шапки файла):

```markdown
## YYYY-MM-DD — краткий заголовок

### Проблема
…

### Фикс
…

### Проверка
…
```

Писать при багфиксах для клиентов, смене промптов/правил, миграциях. Не писать при typo без смены поведения.
