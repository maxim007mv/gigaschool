# Principal code review (КАРКАС)

Глубокий code review: безопасность, БД, конкурентность, архитектура, наблюдаемость, производительность.

## Режимы

| Режим | Когда | Вывод |
|-------|-------|--------|
| Ручной | Запрос ревью по файлам/модулю | Вердикт, замечания, эталонный код модуля |
| Авто | После собственного diff перед merge | Найденное → исправить → краткий отчёт |

## Чек-лист КАРКАС

- API: JWT, org scope, rate limit, problem+json.
- Human Gate: 409 `GATE_NOT_PASSED`, триггер `program_gate`.
- Часы только в `topic_workload`; солвер в `domain/hours.py`.
- Реестры НПА/ПС/ПО — без выдуманных кодов; источники через S17/S18.
- `datetime.now(timezone.utc)`, деньги — `Decimal`.
- Pydantic v2, слои domain / agent / api / infra.
- Важные изменения — запись в `changelog.md`.

## Авто-режим (краткий отчёт)

```
Самопроверка:
- [исправлено] path:line — проблема → фикс
- [ок] измерения без замечаний
```
